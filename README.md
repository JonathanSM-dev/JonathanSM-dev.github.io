# Site de teste do WebSec Inspector

Site estático para validar o fluxo do WebSec Inspector, publicado na raiz de https://jonathansm-dev.github.io/.

## Configurar a prova

Após informar a URL no app, copie a meta tag recebida e insira-a no head de index.html, substituindo o comentário reservado. Faça commit e aguarde o deploy do GitHub Pages. Confirme que a tag aparece no código-fonte público antes de confirmar a verificação no app.

Não use JWT, senha ou chave privada nessa tag. O desafio de verificação é público.

Este ambiente não contém vulnerabilidades propositais nem garante achados. O formulário usa apenas GET e não persiste dados. Todos os links HTML permanecem no próprio domínio.
